# Lector para GitHub Pages

Esta carpeta contiene la versión estática de Lector, preparada para publicarse directamente con GitHub Pages.

Admite documentos de Word modernos `.docx`. Los archivos antiguos `.doc` deben abrirse en Word y guardarse como `.docx` antes de cargarlos.

## Publicación

1. Sube el contenido de esta carpeta a la raíz de tu repositorio `lector`.
2. En GitHub, entra en **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama `main`, la carpeta `/ (root)` y pulsa **Save**.
5. La aplicación estará disponible en `https://TU-USUARIO.github.io/lector/`.

La dirección normal del repositorio (`github.com/TU-USUARIO/lector`) seguirá mostrando el README. La aplicación se abre desde la dirección `github.io`.
